Paratext has a feature called "**Adapt Names**" that helps you check that the proper names in your project have been **transliterated** consistently from the source text.

### Using “Adapt Names” {#6c6de65cd2da42e9b80c0127bed26993}

Si vous souhaitez utiliser cette fonctionnalité, consultez les rubriques d'aide Paratext suivantes

- Introduction aux noms propres adaptés.
- Comment adapter les noms propres  ?

### Checking the proper names entered manually {#30b598a5fd4080588db2d6697ee5b7ef}

If you want to check the Proper Names you have entered in your text, use the Biblical Terms list, and filter for category **Names**.

If you find errors that occur multiple times, consider using the Wordlist to correct them all at once.
